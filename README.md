# 改革日本語 (Reformed Japanese)

現代日本語を基礎に、音韻・音節構造・正書法・三音高を改革する言語企画。旧「日本語2045」の助詞廃止／語尾廃止設定は引き継がない。

## 決定事項
- 音節構造：`(C)(C)V(C)(C)`。音節頭・末尾は最大2子音、子音連続は原則自由。
- 母音：`/a i u e o/`、ウは /u/。シは /ʃi/、チは /tʃi/、ラ行は /ɾ/。
- 漢字・歴史的仮名遣いは廃止。語彙はカタカナ、助詞のみひらがな。は→わ、を→お、へ→え。
- アイヌ語用捨て仮名を拡張して独立子音を記す（いくつかの字形は試案）。
- 三音高：M（無標）、H（結合アキュート U+0301）、L（結合グレイヴ U+0300）。アクセント記号は正書法に必須。
- H・Lの直後の音節はMにする。2音節で許可される配列はMM/MH/ML/HM/LM。久留米周辺の抑揚を参考にし、足りない部分は関西弁を参照。
- 現代日本語の文法を原則として維持。同音異義語を音高・語形変更で区別する。

## 基準例文

**ワタシわ リ́ンゴお タベ́ル。**（私はりんごを食べる）

## 注意

母音脱落規則、語彙アクセント辞書、外来語の正書法、拡張捨て仮名の一部字形はまだ暫定。サイトにもその旨を表示する。Unicode結合記号と小書きカタカナの見え方はフォント依存。
